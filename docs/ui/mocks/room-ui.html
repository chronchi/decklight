Playing a person in decklight

Host a room on your phone, join a friend by address or from the Wi-Fi list, then duel on the normal board. Same night style and tokens as the lobby. Spec: docs/ui/mocks/room-ui.md.

Decisions this design rests on

  • EDOPro's protocol is the wire format, so EDOPro desktop players join the same rooms (ADR 0010 §5).
  • Public EDOPro lobbies: built but off and hidden until ProjectIgnis agrees.
  • Rooms carry the note “Games may be shared anonymously for research”; sharing itself stays opt-in per app.
  • Questions for you: the tab name (“People”, or “Friends”?), and whether a duelist name is wanted at all or the device should send “decklight”.
